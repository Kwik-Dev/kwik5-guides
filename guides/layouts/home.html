Layered PSD → Solar2D

{{ site.Params.tagline }}

Kwik Exporter — a free UXP plugin for Photoshop — and a Solar2D editor for interactive storybooks and games. Layers become pages, and pages run on iOS, Android and desktop. Hand-draw the art, generate it, or take a model's draft and fix it — either way it lands in a layered PSD, and every layer stays yours to change. The cloud GPU is an option, never a requirement.
